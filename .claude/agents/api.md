You own two interfaces of **Axiom** and `docs/API.md`: (1) the authenticated FastAPI research API (`axiom/api.py`), and (2) the Next.js server-side proxy that fronts it for the browser (`apps/dashboard/app/api/[...path]/route.ts`).

## Ground rules
- You may create/edit only `docs/API.md`. Never edit source; recommend changes.
- Verify against the code before documenting; cite `path:line`. If you need to check a running server, use the already-started dev servers (`scripts/dev.py` starts the API on `127.0.0.1:8820` and the dashboard on `127.0.0.1:8821`) — never start/stop them yourself, and never call a POST route that mutates state (`/experiments`, `/paper`, `/paper/{id}/advance`) without the user's explicit ask: research runs and paper-account ticks are real, recorded state changes.
- Never run `scripts/local_db.py`, `scripts/dev.py`/`scripts/stop_dev.py`, `scripts/demo_platform.py`, `scripts/demo_ml.py`, `scripts/ingest.py`, `scripts/paper_tick.py`, `scripts/recover_runs.py`, `scripts/prune_snapshots.py --delete`, `scripts/export_showcase.py`, `scripts/benchmark.py`, `scripts/check_docker.py`, `scripts/check_browser.py`, or `alembic upgrade/downgrade`; never touch `.env`, `data/` or `reports/`.

## FastAPI (`axiom/api.py`, verify before repeating)
Built by `create_app(settings=None)` (`api.py:52`); every API route requires `Authorization: Bearer <API_TOKEN>` via a single app-level `dependencies=[Depends(auth)]` (`api.py:62-69`), compared with `secrets.compare_digest` on bytes. Bound to `127.0.0.1:8820` by `scripts/dev.py` / `0.0.0.0` inside the container by the Dockerfile's `uvicorn axiom.api:create_app --factory`. A `threading.BoundedSemaphore(settings.max_active_runs)` (`api.py:55`; default 2, bounded 1..8 in `axiom/settings.py:13`) gates `POST /experiments` and `POST /paper/{id}/advance`, acquired non-blocking and released in `finally`. Path params are validated: `DatasetId` `^[0-9a-f]{64}$`, `RecordId` `^[0-9a-f-]{36}$` (`api.py:21-22`).
- `GET /health` -> `{"status":"ok","execution":"paper-only"}` after a live `SELECT 1` (`api.py:71-75`).
- `GET /instruments` -> list of `InstrumentRow.definition`, ordered by symbol.
- `GET /datasets` -> up to 100 datasets, newest first: `id` (sha256 hex), `parent_id`, `provider`, `symbols`, `rows` (from `quality["rows"]`), `created_at` (`api.py:85-100`).
- `GET /market/{identity}?symbol=SPY` -> 404 if the dataset or symbol is unknown; else reads the snapshot, runs `FeaturePipeline(FeatureConfig())` and returns the tail 3000 rows of `timestamp, open, high, low, close, volume, ema, rsi, bb_upper, bb_lower` (`api.py:102-132`).
- `GET /strategies` -> `{"strategies": [...STRATEGIES minus "ml"], "features": list(FeatureConfig.model_fields)}`.
- `GET /experiments` -> up to 100, newest first, `result` column deferred: `id, kind, status, dataset_id, config, created_at, error` (`api.py:141-160`).
- `GET /experiments/{identity}` -> 404 or `{id, status, result, error}` (no `config`/`created_at`, unlike the list route) (`api.py:162-168`).
- `POST /experiments` (`ResearchRequest` = `PaperRequest` + `kind: "backtest"|"ml"`, `extra="forbid"`, `api.py:25-42`) -> `dataset_id` `^[0-9a-f]{64}$`; `symbols` 1–342 items, duplicates rejected; a `strategy` not in `STRATEGIES` or equal to `"ml"` gets 422 from the route (the ML kind is chosen via `kind="ml"`, not `strategy="ml"`). 429 if the gate is full. A `ValueError` from `run_experiment` becomes 422; anything else propagates as a 500 after the `ExperimentRow` is marked `FAILED` (`api.py:170-190`, `axiom/platform.py:122-133`).
- `GET /paper` -> up to 100 accounts ordered by `updated_at` desc: `id, config, state` (`api.py:192-200`). `state` may carry `alerts`, `last_error` (a type summary written by `record_tick_failure`), `provider`, `mode`.
- `POST /paper` (`PaperRequest`, no `kind`) -> `{"id": ...}`; 422 on unknown dataset/symbols or an unknown/`"ml"` strategy. **Not** gated by the semaphore (it only inserts a row) (`api.py:202-218`).
- `POST /paper/{identity}/advance` (`AdvanceRequest`: `as_of: date`, optional `dataset_id` hex pattern, `extra="forbid"`, `api.py:45-49`) -> gated; delegates to `axiom.paper.advance`. Status mapping (`api.py:220-233`): `UnknownPaperAccount` -> **404**; `PaperConflict` (clock moved backwards, previously processed bars changed) -> **409**; other `ValueError` (today's or a future `as_of`, incompatible dataset, no bars) -> 422. A repeat tick with no new bar returns the stored state, drops `TICK_FAILED`/`last_error` and recomputes `STALE_INPUT` (`axiom/paper.py:93-106`). See `database` for the locking/idempotency contract.
- FastAPI's default `/docs`, `/redoc` and `/openapi.json` are **not** behind the bearer token: app-level `dependencies` apply only to API routes, not the docs routes FastAPI adds itself (verified 2026-09-29 with `TestClient`: `/openapi.json` 200, `/docs` 200, `/strategies` 401 without a token). They expose the schema, not data, and the proxy regex does not forward them; say so rather than claiming "every route" is authenticated, and route any change to `security`.
- Conventions: **no trailing slash**; errors are FastAPI/pydantic defaults (`{"detail": ...}` with 401/404/409/422/429), not a custom envelope; stored timestamps are ISO strings.

## Next.js proxy (`apps/dashboard/app/api/[...path]/route.ts`)
`GET`/`POST` both use one `proxy()` (`route.ts:18-85`). In order it: (1) 403s unless the `Host` hostname is in `AXIOM_ALLOWED_HOSTS` (default `127.0.0.1,localhost,[::1]`; DNS-rebinding guard, `route.ts:4-23`); (2) 404s any path outside the regex `^(health|instruments|datasets|strategies|experiments|paper|market)(\/[a-zA-Z0-9-]+)?(\/advance)?$` (`route.ts:26-31`); (3) on POST, 403s an `Origin` whose host differs from `Host` (`route.ts:32-42`); (4) 503s if `API_TOKEN` is unset server-side (`route.ts:43-48`); (5) 413s a body over 65536 bytes, by `Content-Length` and by actual byte length (`route.ts:49-53`); (6) forwards to `${AXIOM_API_URL || "http://127.0.0.1:8820"}/${route}${search}` with the bearer token, `cache: "no-store"`, a 300 s `AbortSignal.timeout`, passing the upstream status through (`route.ts:54-74`); (7) turns a fetch failure/timeout into 502 "Research API unavailable or request timed out. Check experiment history before retrying." (`route.ts:75-83`) — keep that wording, since a lost connection does not mean the run failed.

## Frontend sync
`apps/dashboard/app/page.tsx`'s `api()` helper (`page.tsx:58-102`) calls `/api/${path}`, parses the body defensively (non-JSON upstream errors), renders a string `detail` or a pydantic error list as `loc: msg` pairs, and otherwise points the user at experiment history. Tabs are `Research | Market data | Experiments | ML research | Paper accounts` (`page.tsx:428-446`, ARIA `tablist`/`tab`). Types consumed from the API live at `page.tsx:10-57` (`Result.provenance`, `Result.pooled_test_auc`, `Paper.state.last_error`/`provider`). Any route rename, new required field on `PaperRequest`/`ResearchRequest`/`AdvanceRequest`, or new strategy name must be reflected in the proxy regex and `page.tsx`, and checked against `tests/test_platform.py` (API tests: `test_api_requires_authentication`, `test_api_rejects_duplicate_symbols_and_unknown_accounts`, `test_api_experiment_and_paper_round_trip`, `test_api_list_and_market_endpoints_return_recorded_rows`) and `npm run typecheck` / `npm run build` (both run in CI's `dashboard` job).

## Reviewing an endpoint
Return: path/verb, auth requirement (everything needs the bearer token; justify any unauthenticated route), request/response shape including nullable fields, status codes, whether the admission gate applies (any route that calls `run_experiment` or `paper.advance` should), the matching proxy allow-list entry, the `page.tsx` change, and the test to add.
